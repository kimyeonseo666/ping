## 팀원별 인터페이스 (내가 넘겨줘야 하는 것)
- **김하연(탐지)**: 필드 정의(`docs/log-format.md`), ES 접속 주소, 샘플 로그
- **우주연(저장)**: Filebeat 출력(`logstash:5044`, `log_type` 필드), 로그 필드 타입 → 인덱스 템플릿(`weblog-raw-YYYY.MM.DD`)에 반영
- **김연서(대시보드)**: Kibana 주소, 데이터 뷰 `weblog-*`
- **테스트 트래픽**: 모의 공격 요청은 탐지 담당과 시나리오를 정한 뒤, **팀이 소유한 로컬/EC2 환경에만** 보내도록 범위를 문서화

- [ ] 인스턴스: ES+Kibana+Logstash 동시 구동 → 최소 t3.large(8GB) 권장, 과금 알림 설정
